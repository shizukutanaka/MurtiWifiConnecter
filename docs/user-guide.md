# MWC ユーザーガイド

MWC (Multi WiFi Connector) は Windows / Linux / macOS で動作する Wi-Fi 管理ツール。複数アダプターの同時管理、QR コード共有、企業向け EAP-TLS 認証に対応する。

## インストール

### Windows

```powershell
# winget
winget install ShizukuTanaka.MWC

# Scoop
scoop install mwc

# Chocolatey
choco install mwc
```

### CLI (クロスプラットフォーム)

```bash
dotnet tool install --global MWC.Cli
```

## 基本操作 (GUI)

起動すると利用可能な Wi-Fi アダプターと周辺ネットワークが一覧表示される。

ネットワークに接続するには、一覧から SSID を選び「接続」を押す。保護されたネットワークではパスフレーズの入力を求められる。一度接続したネットワークは履歴に保存され、次回以降は自動再接続の候補になる。

複数の Wi-Fi アダプターを搭載している場合、各アダプターを独立して別々のネットワークに接続できる。これは一方を社内ネットワーク、もう一方をモバイルテザリングに繋ぐといった用途に有効。

## QR コードでの共有

接続済みネットワークの QR コードを表示すると、スマートフォンのカメラでスキャンするだけで他のデバイスを同じネットワークに接続できる。表示するには対象ネットワークを右クリックして「QR コードを表示」を選ぶ。

QR コードは標準の `WIFI:` URI スキームに準拠しているため、iOS / Android の標準カメラアプリで読み取れる。

## 企業向け機能

### EAP-TLS クライアント証明書

企業ネットワークで証明書ベース認証を使う場合、接続ダイアログで「証明書を選択」を押すと Windows 証明書ストアから利用可能なクライアント証明書が一覧表示される。証明書の有効期限は色で示され、期限が近いものは警告色で表示される。

### eduroam

大学や研究機関の eduroam ネットワークには、CAT (Configuration Assistant Tool) からダウンロードした設定ファイル (`.eap-config`) をインポートして接続できる。設定 → eduroam インポートから XML ファイルを選ぶだけで接続プロファイルが自動生成される。

### Group Policy / Intune

IT 管理者は Group Policy または Microsoft Intune で MWC の動作を制御できる。接続可能な SSID のホワイトリスト、設定変更の禁止、最低セキュリティレベルの強制などが可能。詳細は管理者向けドキュメントを参照。

## テーマ

設定からアプリのテーマを変更できる。System / Dark / Light に加え、Windows 11 公式の Fluent デザイン、Solarized、Nord、Catppuccin の各テーマを選べる。Fluent テーマは Windows の Light/Dark モード切り替えに自動追従する。

## 言語

15 言語に対応 (日本語 / 英語 / 中国語簡体・繁体 / 韓国語 / スペイン語 / フランス語 / ドイツ語 / ロシア語 / アラビア語 / ポルトガル語 / ヒンディー語 / ベンガル語 / タミル語)。設定から変更できる。

## キーボードショートカット

| ショートカット | 動作 |
|---|---|
| Ctrl+R | ネットワークを再スキャン |
| Ctrl+, | 設定を開く |
| Enter | 選択中のネットワークに接続 |
| F1 | ヘルプを表示 |

全機能はキーボードのみで操作可能 (WCAG 2.1 AA 準拠)。スクリーンリーダー (NVDA / JAWS / ナレーター) に対応している。
