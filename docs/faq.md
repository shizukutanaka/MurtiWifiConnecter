# よくある質問 (FAQ)

## 一般

### MWC は無料ですか

MIT ライセンスのオープンソースソフトウェア。無料で利用・改変・再配布できる。

### どのプラットフォームで動作しますか

Windows 10 (2004 以降) / Windows 11 でフル機能が利用できる。Linux (NetworkManager) / macOS (CoreWLAN) でも CLI とコア機能が動作する。Android / iOS はモバイルアプリ版として提供される。

### 管理者権限は必要ですか

Wi-Fi プロファイルの登録・接続には管理者権限が必要な場合がある。スキャンや一覧表示は通常のユーザー権限で動作する。

## 接続

### 接続に失敗します

まずパスフレーズが正しいか確認する。MWC は最大 2 回まで自動的に再試行する。それでも失敗する場合、トラブルシューティングガイドを参照。認証情報が誤っている場合は再試行せず即座にエラーが表示される。

### 6 GHz 帯のネットワークが表示されません

6 GHz (Wi-Fi 6E / Wi-Fi 7) は国・地域によって利用可否と使用可能チャネルが異なる。MWC は現在のシステムロケールから規制ドメインを判定し、その地域で合法なチャネルのみを表示する。日本・米国は全帯域、EU は下半分のみ、中国・インドは現時点で未認可。

### 複数のアダプターを同時に使えますか

はい。各 Wi-Fi アダプターを独立して別々のネットワークに接続できる。同一アダプターへの並列接続要求は内部で順序化され、ドライバーの不整合を防止する。

## セキュリティ

### パスワードはどこに保存されますか

Windows では DPAPI (Data Protection API) で暗号化して OS の資格情報ストアに保存する。平文での保存は一切行わない。

### MWC は通信内容を収集しますか

いいえ。MWC は個人を特定する情報 (PII) を収集しない。接続履歴はローカルにのみ保存され、外部送信されない。テレメトリは存在しない。

### OWE (Enhanced Open) とは何ですか

WPA3-OWE は、パスワードのないオープンネットワークでも通信を暗号化する仕組み。MWC は同じ SSID にオープン版と OWE 版が両方ある場合、自動的に OWE を優先する。

## 企業利用

### Intune で配布・管理できますか

はい。Group Policy または Intune の OMA-URI で、接続可能 SSID の制限、設定変更の禁止、最低セキュリティレベルの強制などが可能。

### eduroam に接続するには

所属機関の CAT (cat.eduroam.org) から設定ファイルをダウンロードし、MWC にインポートする。EAP-TLS / PEAP-MSCHAPv2 / EAP-TTLS に対応している。

## トラブル

### アプリが起動しない

.NET 9 ランタイムがインストールされているか確認する。winget/Scoop 経由のインストールでは自動的に依存関係が解決される。

### 設定をリセットしたい

設定ファイルは `%LocalAppData%\MWC\` に保存される。このフォルダを削除すると初期状態に戻る。
