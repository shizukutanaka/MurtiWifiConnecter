## 🎬 使い方 - 3ステップで開始

### 1️⃣ インストール
```powershell
# 管理者権限でPowerShellを開く
Set-ExecutionPolicy Bypass -Scope Process -Force
# インストーラーを実行
.\MurtiWiFiConnecterInstaller.exe
```

### 2️⃣ 初期設定
1. アプリを起動
2. 「クイックセットアップ」をクリック
3. 利用環境を選択（家庭・オフィス・公共施設・企業・政府機関）
4. プライバシー設定を確認
5. 「最適化開始」をクリック

### 3️⃣ 自動最適化開始
- **何もする必要はありません！**
- AIが自動的に最適化を開始
- 問題があれば自動で修復
- ダッシュボードで状況を確認可能

## 🖥️ システム要件

### 💻 推奨環境
- **OS**: Windows 10 (1903以降) / Windows 11
- **CPU**: Intel Core i3 / AMD Ryzen 3 以上
- **メモリ**: 4GB RAM以上（8GB推奨）
- **ストレージ**: 500MB 以上の空き容量
- **ネットワーク**: WiFi対応（802.11n以降推奨）

### 🔧 必要コンポーネント
- **.NET 6 Runtime** (自動インストール)
- **Microsoft Visual C++ Redistributable** (自動インストール)
- **Windows WiFi Service** (標準搭載)

## 📋 アーキテクチャ概要

```
SuperiorWifiManager (統合制御層)
├── AdvancedWifiEngine (Windows WLAN API完全活用)
├── WifiIntelligence (機械学習・AI最適化)
├── WifiDiagnosticsEngine (7段階診断フレームワーク)
├── CaptivePortalEngine (多重検出・自動認証)
├── WifiDashboardEngine (リアルタイム可視化)
└── AutomatedTroubleshootingEngine (5フェーズ解決)
```

### 🏗️ 主要コンポーネント
- **WindowsWifiSystemAnalysis.cs** - システム分析・問題特定
- **AdvancedWifiEngine.cs** - コア監視・制御エンジン
- **WifiIntelligenceEngine.cs** - AI最適化システム
- **WifiDiagnosticsEngine.cs** - 診断・自動修復
- **CaptivePortalEngine.cs** - ポータル対応システム
- **WifiDashboardEngine.cs** - 統合ダッシュボード
- **AutomatedTroubleshootingEngine.cs** - 自動問題解決
- **SuperiorWifiManager.cs** - 統合管理システム
