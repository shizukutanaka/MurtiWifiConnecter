# Murti WiFi Connecter

WiFi接続管理アプリケーション

## 機能

### 基本機能
- WiFiネットワークスキャン
- 信号強度表示
- 接続管理
- パスワード管理

### 自動接続機能
- パスワード自動保存
- ダブルクリックで自動接続
- 接続履歴管理
- 最適なネットワークへの自動切り替え

### 接続安定化機能
- 自動再試行（最大3回）
- 切断後の自動再接続
- 接続品質モニタリング
- 接続診断ツール

### パフォーマンス最適化
- メモリ使用量の自動管理
- 軽量なネットワークスキャン
- 効率的なUI更新
- バックグラウンド処理

### システムトレイ統合
- 最小化時にシステムトレイに格納
- トレイアイコンからのクイックアクセス
- 接続状態の通知

## システム要件
- Windows 10/11
- .NET 6.0以上
- 管理者権限（一部機能）

## 使用方法

### 基本的な接続
1. アプリケーションを起動
2. WiFiネットワークリストから接続先を選択
3. パスワードを入力
4. 接続ボタンをクリック

### 自動接続
- ダブルクリック: 保存済みパスワードで自動接続
- クイック接続ボタン: 最近の接続先に自動接続

### キーボードショートカット
- F5: ネットワークリストを更新
- Ctrl+R: ネットワークリストを更新
- Ctrl+Q: クイック接続
- Escape: 接続処理をキャンセル
- Enter: 選択したネットワークに接続

## 設定

設定はQuickSettingsManagerで管理されています。

### 主な設定項目
- `auto_connect`: 自動接続の有効/無効
- `auto_save_passwords`: パスワード自動保存の有効/無効
- `refresh_interval_seconds`: スキャン間隔（秒）
- `max_displayed_networks`: 表示する最大ネットワーク数
- `tray_notifications`: システムトレイ通知の有効/無効

## トラブルシューティング

### 接続できない場合
1. WiFiアダプタが有効になっているか確認
2. 管理者権限で実行してみる
3. Windows Firewallの設定を確認
4. ネットワークドライバを更新

### パフォーマンスの問題
1. 表示ネットワーク数を減らす
2. スキャン間隔を長くする
3. 不要な接続履歴をクリア
