# MurtiWifiConnecter - セットアップガイド

## インストール

### 自動インストール（推奨）
1. **install.bat**を**右クリック**
2. **「管理者として実行」**を選択
3. インストーラーの指示に従ってください

### 手動インストール
1. `bin/`フォルダをお好みの場所にコピー
2. `config/`フォルダを同じ場所にコピー
3. `MurtiWifiConnecter.exe`を右クリック → **「管理者として実行」**

## 初回設定（3ステップ）

### ステップ1: ユーザー情報
- **お名前**: 家族の代表者名を入力
- この名前はシステム内での表示に使用されます

### ステップ2: 家庭ネットワーク（オプション）
- **家庭のWiFi**: 普段使用するWiFiネットワークを選択
- 信頼できるネットワークとして自動登録されます
- スキップしても後で設定可能

### ステップ3: 確認と完了
- 設定内容を確認
- **「設定完了」**をクリック
- システムトレイに常駐開始

## 詳細設定

### 家族プロファイル設定
1. メイン画面 → **「設定」** → **「家族管理」**
2. **「メンバー追加」**をクリック
3. 以下を設定:
   - **名前**: 家族メンバーの名前
   - **年齢区分**: 大人/子供を選択
   - **時間制限**: 使用可能時間を設定（子供の場合）
   - **ネットワーク制限**: 接続可能ネットワークを制限

#### 子供向け制限例
- **小学生**: 平日16:00-20:00、週末9:00-21:00、最大4時間/日
- **中学生**: 平日17:00-21:00、週末9:00-22:00、最大6時間/日
- **高校生**: 平日16:00-22:00、週末8:00-23:00、最大8時間/日

### バッテリー最適化設定
1. 設定 → **「パフォーマンス」** → **「電源モード」**
2. モードを選択:
   - **自動調整**: バッテリー残量に応じて自動調整（推奨）
   - **高性能**: AC電源時の最高性能
   - **バランス**: 通常のバッテリー動作
   - **省電力**: バッテリー20%以下時の省電力
   - **超軽量**: バッテリー10%以下時の最軽量

### 信頼ネットワーク管理
1. 設定 → **「ネットワーク管理」**
2. **「信頼ネットワーク追加」**
3. 以下を設定:
   - **SSID**: ネットワーク名
   - **表示名**: 分かりやすい名前（例：「実家のWiFi」）
   - **場所**: 家庭/職場/学校/公共
   - **優先順位**: 自動接続の優先度

## 日常の使い方

### システムトレイから（推奨）
- **ダブルクリック**: メイン画面を開く
- **右クリックメニュー**:
  - 📊 **状況確認**: 現在の接続状況を表示
  - 🏠 **安全接続**: 家庭内の信頼ネットワークに接続
  - 🔧 **自動修復**: 問題を自動検出・修復
  - 🔒 **子供モード**: 子供向け制限の有効/無効切替

### コマンドライン操作
```cmd
# CLIモード起動
MurtiWifiConnecter.exe --cli

# 利用可能コマンド
p - 個人モード開始
s - 状況確認
f - 問題自動修復
h - 家庭内安全接続
t - テスト実行
d - 診断実行
```

## トラブルシューティング

### 設定できない場合
- **管理者権限で起動しているか確認**
- ウイルス対策ソフトの例外設定に追加

### 子供制限が効かない場合
- 家族プロファイルが正しく設定されているか確認
- システム時刻が正確か確認
- 他のデバイスから同じアカウントでログインしていないか確認

### バッテリー最適化が動作しない場合
- Windows電源設定を確認
- WMIサービスが動作しているか確認
- 管理者権限で起動しているか確認

## 設定ファイルの場所

### アプリケーション設定
```
%APPDATA%\MurtiWifiConnecter\personal_wifi_settings.json
```

### 家族プロファイル
```
%APPDATA%\MurtiWifiConnecter\home_wifi_settings.json
```

### ログファイル
```
%APPDATA%\MurtiWifiConnecter\Logs\personal_wifi.log
```

## 設定のバックアップ
重要な設定をバックアップする場合:
```cmd
xcopy "%APPDATA%\MurtiWifiConnecter\" "バックアップフォルダ\" /E /I
```
