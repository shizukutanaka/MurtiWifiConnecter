# 🎉 MurtiWifiConnecter v2.0.0 - リリースノート

## 🏠 **個人・家庭利用向け完全リニューアル**

MurtiWifiConnecter v2.0.0は、企業向けから個人・家庭利用に完全特化したメジャーアップデートです。John Carmack、Robert C. Martin、Rob Pikeの設計思想に基づき、シンプルで強力、そして家族みんなが使えるWiFi管理システムに生まれ変わりました。

---

## ✨ **主要新機能**

### 🏠 **家族向け特化機能**
#### **3ステップ簡単設定**
- 技術に詳しくない方でも簡単に設定可能
- ステップ1: ユーザー名入力
- ステップ2: 家庭WiFi登録（オプション）
- ステップ3: 設定確認と完了

#### **家族プロファイル管理**
- **年齢別プロファイル**:
  - 小学生向け: 平日16-20時、週末9-21時、最大4時間/日
  - 中学生向け: 平日17-21時、週末9-22時、最大6時間/日
  - 高校生向け: 平日16-22時、週末8-23時、最大8時間/日
  - 大人向け: 制限なし
- **時間制限機能**: 使用可能時間帯の設定
- **ネットワーク制限**: 接続可能ネットワークの制限
- **安全モード**: 子供向けの安全なインターネット利用サポート

#### **信頼ネットワーク管理**
- 家庭、職場、学校、公共の場所別管理
- 自動接続優先順位設定
- 安全なネットワークへの自動切替

### 🔋 **バッテリー最適化システム**
#### **4段階電源モード**
- **UltraLightweight**: バッテリー10%以下時（最小限機能のみ）
- **PowerSaver**: バッテリー20%以下時（省電力モード）
- **Balanced**: 通常のバッテリー動作（標準モード）
- **HighPerformance**: AC電源接続時（最高性能）

#### **自動調整機能**
- バッテリー残量に応じた自動最適化
- WMIリアルタイム監視による正確な電源状況把握
- スマート監視: バッテリー時は監視間隔を2分に延長
- ノートPC利用者向けのバッテリー寿命延長

### 🛠️ **ワンクリック操作**
#### **自動修復機能**
- 問題の自動検出と修復
- 接続トラブルのワンクリック解決
- 診断結果の分かりやすい表示

#### **システムトレイ統合**
- バックグラウンドでの静かな動作
- 右クリックメニューから主要機能にアクセス
- 📊 状況確認、🏠 安全接続、🔧 自動修復、🔒 子供モード

#### **パーソナルダッシュボード**
- 接続状態、信号強度、バッテリー状況の統合表示
- リアルタイムでの状況監視
- 家族メンバーの利用状況確認

## 🎯 **システム要件**

### 必須要件
- **OS**: Windows 10 (1903以降) または Windows 11
- **ランタイム**: .NET 6.0 Runtime
- **権限**: 管理者権限（WiFi操作に必要）
- **メモリ**: 最小512MB RAM
- **ストレージ**: 50MB以上の空き容量

### 推奨要件
- **メモリ**: 1GB以上のRAM
- **ストレージ**: 100MB以上の空き容量
- **ディスプレイ**: 1280x720以上の解像度

## 🚀 **インストール方法**

### 自動インストール（推奨）
1. **install.bat**を**右クリック** → **管理者として実行**
2. インストーラーの指示に従う
3. 完了後、3ステップ設定ウィザードを実行

### 手動インストール
1. 配布パッケージを任意の場所に展開
2. **MurtiWifiConnecter.exe**を管理者として実行
3. 初回起動時の設定ウィザードを完了

## 🔄 **マイグレーション情報**

### v1.x.x（企業向け）からの移行
v1.x.xの企業向け機能は個人・家庭利用には適さないため、v2.0.0では完全にリニューアルしました。企業向けの複雑な機能（AI、機械学習、Active Directory統合等）は削除し、家庭で本当に必要な機能に集中しています。

### 設定の互換性
v1.x.xとv2.0.0では設定形式が完全に変更されているため、新規インストールとして扱われます。v2.0.0の3ステップ設定ウィザードで簡単に初期設定を完了できます。

## 🐛 **既知の問題と制限**

### 制限事項
- Windows 10の古いバージョン（1903未満）では動作しない可能性があります
- ARM64版Windowsでは動作確認が必要です
- 仮想マシン環境では一部機能が制限される場合があります

### 解決済みの問題
- 企業向け機能の複雑さによる使いにくさ → 個人向け特化で完全解決
- 高いメモリ使用量 → 軽量設計で30MB未満に削減
- 複雑な設定手順 → 3ステップ設定で簡素化
