## GitHub Release Creation (using gh cli)
gh release create v2.0.0 \
  --title "MurtiWifiConnecter v2.0.0 - Personal Edition" \
  --notes-file release/RELEASE_NOTES_v2.0.0.md \
  --prerelease=false \
  --generate-notes

## Upload Release Assets
gh release upload v2.0.0 release-package.zip
gh release upload v2.0.0 MurtiWifiConnecter-v2.0.0-Setup.exe

## Alternative: Create Release with Binary
gh release create v2.0.0 ./MurtiWifiConnecter-v2.0.0.zip \
  --title "MurtiWifiConnecter v2.0.0 - Personal Edition" \
  --notes "See RELEASE_NOTES_v2.0.0.md for detailed changelog"
