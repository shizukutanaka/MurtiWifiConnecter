# MurtiWifiConnecter - 配布ガイド

## パッケージ構成

```
release/
├── bin/                    # 実行ファイル群
│   ├── MurtiWifiConnecter.exe    # メインアプリケーション
│   ├── MurtiWifiConnecter.exe.config
│   └── 必要なDLLファイル群
├── config/                 # 設定ファイル
│   ├── default_settings.json     # デフォルト設定
│   └── family_profiles.json      # 家族プロファイルテンプレート
├── docs/                   # ユーザー向けドキュメント
│   ├── README.md                 # 使い方ガイド
│   ├── SETUP_GUIDE.md           # インストールガイド
│   └── TROUBLESHOOTING.md       # トラブルシューティング
├── DEPLOYMENT_GUIDE.md     # このファイル
└── install.bat            # 簡易インストーラー
```

## システム要件

### 必須要件
- **OS**: Windows 10 (1903以降) または Windows 11
- **アーキテクチャ**: x64 (64ビット)
- **ランタイム**: .NET 6.0 Runtime または .NET 6.0 SDK
- **権限**: 管理者権限（WiFi操作に必要）
- **メモリ**: 最小512MB RAM
- **ストレージ**: 50MB以上の空き容量

### 推奨要件  
- **メモリ**: 1GB以上のRAM
- **ストレージ**: 100MB以上の空き容量
- **ディスプレイ**: 1280x720以上の解像度

## インストール手順

### 自動インストール（推奨）
1. **install.bat**を**右クリック** → **管理者として実行**
2. インストーラーの指示に従う
3. 完了後、デスクトップのショートカットまたはスタートメニューから起動

### 手動インストール
1. **bin/**フォルダを任意の場所（例: `C:\Program Files\MurtiWifiConnecter\`）にコピー
2. **config/**フォルダを同じ場所にコピー  
3. **MurtiWifiConnecter.exe**を右クリック → **管理者として実行**
4. 初回起動時の3ステップ設定ウィザードを完了

## 初回設定

### 3ステップセットアップ
1. **ステップ1**: ユーザー名を入力（家族の代表者名）
2. **ステップ2**: 家庭のWiFiネットワークを登録（オプション）
3. **ステップ3**: 設定確認と完了

### 家族プロファイル設定（オプション）
- メイン画面 → 設定 → 家族管理
- 家族メンバーを追加し、必要に応じて制限を設定
- 子供の場合: 使用時間制限、ネットワーク制限を設定可能

## 配布時の注意事項

### セキュリティ
- 実行ファイルはWindows Defenderでスキャン済みであることを確認
- 配布前にウイルス対策ソフトでの検証を推奨
- デジタル署名の追加を検討（企業配布の場合）

### 互換性
- Windows 10の古いバージョン（1903未満）では動作しない可能性
- ARM64版Windowsでは動作確認が必要
- 仮想マシン環境では一部機能が制限される場合あり

### ライセンス
- MITライセンスのもとで配布
- 商用利用可能、改変可能
- ライセンス表示の義務あり

## トラブルシューティング

### よくある問題

#### インストール時
- **管理者権限エラー**: install.batを右クリック → 管理者として実行
- **.NET Runtime不足**: Microsoft公式サイトから.NET 6.0 Runtimeをダウンロード
- **アンチウイルス警告**: ウイルス対策ソフトの例外設定に追加

#### 起動時
- **権限エラー**: アプリを右クリック → 管理者として実行
- **設定ファイルエラー**: config/フォルダが正しく配置されているか確認
- **WiFiアダプターエラー**: WiFiアダプターが有効になっているか確認

#### 動作時
- **接続できない**: 「自動修復」機能を実行
- **システムトレイに表示されない**: タスクマネージャーでプロセス終了後、再起動
- **メモリ使用量が多い**: 設定 → パフォーマンス → 軽量モードを有効化

## アップデート手順

### 新版への更新
1. 現在の設定をバックアップ（%APPDATA%\MurtiWifiConnecter\）
2. アプリケーションを終了
3. 新しいbin/フォルダで既存ファイルを置き換え
4. アプリケーションを再起動
5. 設定が正常に引き継がれているか確認

### 設定のバックアップ/リストア
```batch
# バックアップ
xcopy "%APPDATA%\MurtiWifiConnecter\" "backup_folder\" /E /I

# リストア  
xcopy "backup_folder\*" "%APPDATA%\MurtiWifiConnecter\" /E /Y
```
